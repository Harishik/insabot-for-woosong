# University Proposal Summary

InsaBot for Woosong is a verified multilingual AI assistant designed to reduce repetitive university inquiries while improving student access to trustworthy information. It provides source-grounded answers, citations, confidence levels, language support, arrival guidance, office routing, and an admin dashboard that reveals missing FAQ content.

Differentiators:

- Verified answer cards with official source links.
- Multilingual retrieval and response strategy.
- Human handoff for low-confidence or sensitive topics.
- FAQ gap mining for staff.
- Policy change detection through crawl hashing and admin approval.
- Cultural context and Daejeon life support inspired by the original InsaBot idea.
